# Card scripting notes

All 152 cards are scripted. Where card text, rules and rulings left room for
interpretation, or where a shortcut was taken, it is listed here so a player
can check it. Anything marked **Review** is the most likely to be wrong.

## Engine-wide choices

| Topic | What the engine does | Why |
| --- | --- | --- |
| Order of pending effects | Turn player's first (10.13); each player picks the order of their own when they have more than one | Rule 10.12, confirmed by Henry |
| Simultaneous defeats | Units defeated together (a tied fight, Adam Smasher - Metal Over Meat) leave play at once; all their triggers go to pending together and each player orders their own | Confirmed by Henry |
| Calling a Legend | Flips a random face-down Legend | You can't look at your own face-down Legends (5.7.4.1). T-Bug is the exception: after looking, you choose |
| Go Solo | Legend must be face-up | Face-down cards have no cost (3.4.1) |
| "Must attack next turn if it can" | The player can't pass while that Unit has a legal attack | Confirmed by Henry: any target, any time before the turn ends |
| Selling through an effect | Doesn't use up the once-per-turn Sell action | Rule 5.8.2.3, confirmed by Henry |
| Null Street Cred | Lower than 0 in comparisons; counts as 0 for differences | 5.11.4.2; Street Cred with no Gigs is 0 (confirmed by Henry) |
| Optional replacement (Jackie Welles - Mama's Favorite) | Offered for every friendly Unit that would be defeated; payment taken automatically from Eddies first | Payment choice rarely matters. Jackie can defeat himself to save another Unit, face-up in the Legends area or deployed (confirmed by Henry) |

## Card-specific notes

| Card | Note |
| --- | --- |
| Arasaka Emergency Radioport | Looks at a random face-down Legend, unless an earlier look showed one that fits, in which case it picks that one (confirmed by Henry) |
| Bootleg Black Sapphire Show | See "Selling through an effect" above |
| Dexter DeShawn - One Last Chance | Null Street Cred counts as 0 when working out a 10+ difference |
| Gunpoint Diplomacy | "Next time this Unit attacks" permission lasts until the end of turn |
| Hanako Arasaka - In a Gilded Cage | Takes every matching card automatically (always at least as good) |
| Jackie Welles - Mama's Favorite | See engine-wide notes |
| Johnny Silverhand - Rocking Renegade | Cost reduction for 8+ Gigs applied when activating; it can reach 0 and he must still be spent (confirmed by Henry) |
| Kerry Eurodyne - Axe, Attitude, Audience | Draws only if the kept roll is a min or max: the first roll if you don't reroll, otherwise the reroll. A min or max that you reroll away gives nothing (confirmed by Henry) |
| Kiroshi Optics | The look is recorded, but agents don't use the knowledge yet |
| Pepe Najarro | Only face-up Legends count as MERC (face-down cards have no tags; confirmed by Henry) |
| Reboot Optics | Used up by the next fight between a rival Unit and a friendly Unit, even if the friendly Unit would have survived (confirmed by Henry) |
| Saul Bright | Readies the 3 highest-power spent Units automatically |
| Viktor Vektor - Sit Down and Relax | Takes the first 2 eligible Gears automatically |
| Yorinobu Arasaka - Steel Dragon | Draws only for the first ARASAKA Unit (any player's) defeated each turn, counting defeats before he entered play that turn. He draws when he is that first Unit himself. If several ARASAKA Units are defeated together first (two Yorinobu tying), each Yorinobu among them or on the field draws once (confirmed by Henry) |
